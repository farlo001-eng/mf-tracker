## Current State (2026-06-03)

Per-property `extra` JSONB column added. The full imported CSV row is now stored in
`properties.extra` and surfaced in the property detail view under a collapsible
"All property data" section. The condensed list view is unchanged.

### What was done
- db.js: Added `alter table properties add column if not exists extra jsonb` migration
  to SCHEMA — runs idempotently on boot via ensureSchema, migrates Railway DB automatically.
- server.js: GET /api/properties now selects explicit columns (no `p.*`) to keep the
  list payload lean. POST /api/import stores `r.extra` (the full raw CSV row object) as
  JSONB; upsert also updates `extra` on conflict.
- client/src/App.jsx: ImportModal sets `o.extra = r` so the raw row travels to the
  server. PropertyRow detail view renders a `<details>` disclosure with all non-empty
  key/value pairs from `detail.extra`.

### Next step
Re-import any existing markets to populate `extra` for pre-existing rows (rows imported
before this change will have `extra = {}`). No other pending work.
