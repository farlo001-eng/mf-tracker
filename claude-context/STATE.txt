## Current State (2026-06-03)

The property list has been replaced with an inline-editable spreadsheet-style table.
Cells in the table (Property Name, Address, City, Units, Year Built, Status, Follow-up)
can be edited in place; clicking a cell activates an input. Status is a dropdown.
Owner/phone/email remain in the expandable detail row only.

### Architecture
- TABLE_COLS defines the 7 visible columns; `extra: true` columns read/write from
  `p.extra` (JSONB) via the `colVal` / `colPatch` helpers.
- CellEdit handles click-to-edit for text, number, and date cell types.
- PropertyRow now renders as a React Fragment with two `<tr>` elements: the data row
  and a collapsible detail row spanning all columns.
- PATCH /api/properties/:id merges `extra` using `extra || $N::jsonb` (additive merge,
  not a full overwrite).
- GET /api/properties returns `p.extra` so table columns backed by extra are populated
  without an extra fetch.

### What was done
- styles.css: appended .tbl-wrap, .tbl, .tbl-row, .tbl-ctl, .tbl-detail, .cell-view,
  .cell-input, .cell-sel, .cell-exp classes.
- server.js: GET /api/properties select now includes p.extra; PATCH handler merges
  incoming extra object with existing JSONB using the || operator.
- App.jsx: TABLE_COLS array + colVal/colPatch helpers added after FIELDS; Tracker
  container maxWidth widened to 1180; list div replaced with tbl-wrap/table; PropertyRow
  rewritten as <tr> pair; CellEdit component inserted before Editable.
